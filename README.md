A token launch radar: it reads a sealed DefiLlama snapshot, finds every protocol that records no token yet (and is not a wrapped, staked or bridged product of one that trades), ranks them by an implied launch value learned from the snapshot's own live-token peers, and gives each a concrete farm plan in a static, no-network dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```

Then open `out/dashboard/index.html` in a browser. The program also writes `out/board.json` (the ranked board), `out/data.js` (the dashboard's data) and `out/dossier.json`.
